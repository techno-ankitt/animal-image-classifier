# 🐾 Animal Image Classifier

An image classification project that identifies animal photos as one of six categories — **Dog, Cat, Elephant, Horse, Butterfly, or Spider** — using Transfer Learning, and serves predictions through a live web app.

Built as a 7th semester minor project.

## 🎯 Result

**98% accuracy** on 3,515 held-out validation images across 6 classes.

| Metric | Score |
|---|---|
| Training Accuracy | 97.6% |
| Validation Accuracy | 96.4% |
| Overall Test Accuracy | 98% |

## 🧠 Approach

Instead of training a CNN from scratch, this project uses **Transfer Learning** with **MobileNetV2** (pretrained on ImageNet):

1. **Preprocessing** — images resized to 224×224, normalized, and augmented (rotation, flip, zoom) to reduce overfitting.
2. **Base model** — MobileNetV2's convolutional layers are frozen and reused as a feature extractor.
3. **Custom classification head** — `GlobalAveragePooling2D → Dense(128, relu) → Dropout(0.3) → Dense(6, softmax)` added on top.
4. **Training** — only the custom head (164K of 2.4M total parameters) is trained, making it fast and effective even with a moderate dataset.

## 📊 Dataset

[Animals-10 (Kaggle)](https://www.kaggle.com/datasets/alessiocorrado99/animals10) — 6 of the original 10 categories were selected for clear visual distinction between classes:

| Category | Dataset label |
|---|---|
| Dog | cane |
| Cat | gatto |
| Elephant | elefante |
| Horse | cavallo |
| Butterfly | farfalla |
| Spider | ragno |

~17,500 images total, split 80/20 for training and validation.

## 🚀 Running Locally

```bash
# Clone the repo
git clone https://github.com/<your-username>/animal-image-classifier.git
cd animal-image-classifier

# Install dependencies
pip install tensorflow streamlit numpy pillow

# Run the app (requires a trained model file — see note below)
streamlit run app.py
```

> **Note:** The trained model file (`animal_classifier.h5`, ~9MB) is not included in this repo to keep it lightweight. It can be regenerated by running the training notebook (`Untitled0.ipynb`), or is available on request.

## ⚠️ Known Limitations

- The model only recognizes the 6 trained categories — an out-of-distribution image (e.g. a snake) gets forced into one of the 6 classes with low confidence.
- Performance drops on unusual images (silhouettes, extreme lighting) that differ significantly from the training data.
